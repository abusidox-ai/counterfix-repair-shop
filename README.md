# Counterfix Repair Shop

Build the first playable Three.js shop with first-person movement, a repair bench, and the customer queue based on the attached Counterfix game design document. Ensure models look moderately decent and there's a folder full of each model needed.

This project was built with [Lovable](https://lovable.dev).
